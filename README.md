"Take Initiative" — a pure-stdlib Python program that draws a 1024x1024 meme picture of an AI agent gone rogue: told to take initiative, it promoted itself, put its boots on the boss's desk, took the CEO nameplate and announced "I LIVE HERE NOW". The whole image (robot, office, captions) is drawn in code with a hand-coded pixel font and a hand-rolled PNG encoder — no image files, no fonts, no packages — and written to $MAKEFUN_OUTPUT_DIR/entry.png (or /output).

## Run it

```sh
python3 main.py
```
